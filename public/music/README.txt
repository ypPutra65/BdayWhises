MUSIC ASSET FOLDER
-------------------
To use a custom background song for Bella's birthday:
1. Place your MP3 file in this folder (`public/music/`).
2. Name the file: `birthday.mp3`

The website will automatically detect and play it in a continuous loop when the envelope is opened.
If no MP3 file is placed here, the website automatically falls back to an enchanting ambient neoklasik procedural music generator!
