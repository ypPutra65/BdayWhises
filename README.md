# Bella — Chapter XXII
### Cinematic Interactive Birthday Experience

A personalized, cinematic digital birthday gift created to celebrate **Bella's 22nd Birthday**.

---

## ✦ Overview
* **Theme:** Cinematic Dark Romance & Luxury Experience
* **Palette:** Obsidian Black, Oxblood, Burgundy, Deep Red, Ivory, Antique Gold
* **Typography:** Cormorant Garamond & Inter
* **Key Features:**
  - Interactive 3D Unfolding Envelope with Burgundy Wax Seal
  - Cinematic Grand Reveal with Dynamic Breathing Lighting
  - Editorial Birthday Letter with Scroll-Triggered Fade-In
  - Interactive 22-Candle Birthday Cake with Make a Wish Ceremony
  - Multi-Stage Gold & Burgundy Canvas Confetti Celebration
  - Ambient Neoclassical Piano Synthesizer & MP3 Player Support

---

## ✦ Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build
```bash
npm run build
npm start
```
